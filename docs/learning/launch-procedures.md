# Launch procedures: how to read them

**What they are:** Five checklists (docs/procedures/00 to 04) that take Scoudouc from a table to a first hop. Each has a purpose, items, steps with go/no-go checks, what to write down, and abort conditions.

**Why in this order:** each step proves one thing so a failure is easy to explain. The bench shows the electronics work and the igniter circuit cannot fire by accident. The static fire measures what the motor really does. The swing rig shows the control loop steers. Only then does the hop fly.

**Key ideas:**
- Go/no-go means a measured pass/fail, not a feeling.
- Arm switch: a physical switch that cuts the igniter's power, so software mistakes cannot fire it.
- Misfire wait: a motor can light late, so wait 60 seconds before approaching.
- Site distances come from the CAR rules (cleared area grows with motor size).

**What can go wrong:** skipping steps, trusting software instead of the switch, firing in wind, storing a rocket with a motor in it.
