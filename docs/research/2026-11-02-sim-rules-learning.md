# Simulation, Canadian rules, learning path (2026-11-02, haiku, ~112k tokens)

- OpenRocket: ascent only. RocketPy (Python, MIT): custom control laws possible, no built-in gimbal.
- No CAR/Transport Canada rule bans TVC or landing under thrust; approval is case by case via club inspector and CAR HQ. Ask in writing.
- Model-rocket limits: 1,500 g, 125 g propellant, 160 N·s. A failed landing could void an L1 cert flight.
- Québec club: "Club québécois de fuséonautique" on CAR list; site near Montréal unconfirmed.
- Learning links filled into the Notion Learning database (PID, Kalman/Madgwick, thrustcurve.org, PlatformIO, NAR safety code, Wokwi, RocketPy).
