# Simulator

Python. Goal: a 2D rocket model (tilt, height, speed) that takes measured thrust curves, rocket mass, gimbal limits and servo delay, and lets us (1) tune the control loop and (2) search for the landing-burn ignition rule that works across motor-to-motor variation.

Start with the tutorial sketch at https://www.github.com/davud600/rocket-thrust-vector-control, then move to RocketPy if we need 3D.
